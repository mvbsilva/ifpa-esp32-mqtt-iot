# Recursos visuais

- `identidade/`: logo enviada pelo usuário; direitos institucionais reservados.
- `infograficos/`: painel ilustrado da sequência de seis aulas.
- `diagramas/`: diagramas por capítulo (01 a 06).
- `referencias/`: imagem de referência do estilo visual.

Os diagramas são ilustrativos. Antes de montar, siga a pinagem validada em [`docs/montagem.md`](../docs/montagem.md).
