# Aula 04 — Telemetria DHT22 e JSON

**Duração:** 100 minutos.  
**Objetivos:** Ler DHT22 e serializar dados em JSON; Publicar temperatura e umidade a cada cinco segundos.

![Diagrama da aula 4](../../assets/diagramas/diagrama-aula-04.png)

## Roteiro

1. **0–15 min:** revisão, problema motivador e objetivos.
2. **15–30 min:** leitura do diagrama e conceitos necessários.
3. **30–60 min:** montagem e programação guiada.
4. **60–80 min:** integração, depuração e teste.
5. **80–90 min:** exercício de extensão.
6. **90–100 min:** registro de evidências e avaliação.

## Fontes desta etapa

- [`esp32_dht22.ino`](codigo/esp32_dht22.ino)
- [`telemetria_web_aula04.js`](codigo/telemetria_web_aula04.js)
