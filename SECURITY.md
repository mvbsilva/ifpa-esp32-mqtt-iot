# Segurança

**Este repositório é didático.** A configuração Mosquitto com `allow_anonymous true` é somente para laboratório isolado, nunca para produção ou Internet.

Não publique senhas, tokens ou endereços privados. Utilize os arquivos `.example` e mantenha as cópias locais fora do Git. Para sistemas reais, use autenticação, ACL, TLS/WSS, segmentação de rede e proteções elétricas apropriadas.

Se encontrar vulnerabilidade, não divulgue credenciais em issues públicas. Use o canal privado do mantenedor institucional.
