# Como contribuir

1. Abra uma issue descrevendo a correção ou melhoria e a aula afetada.
2. Crie uma branch (`docs/ajuste-aula04`, `fix/telemetria`, etc.).
3. Não inclua senhas, dados de estudantes nem informações privadas.
4. Para código: informe placa, bibliotecas, passos de reprodução e resultado esperado.
5. Para diagramas: mantenha legíveis GPIOs, resistores, alimentação e GND.
6. Para apostilas: mantenha as versões PDF e DOCX alinhadas e preserve identificação institucional.
7. Envie pull request com checklist de testes.

Consulte também [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
